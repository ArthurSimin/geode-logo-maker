# Geode Logo Maker

Browser editor for making 1024x1024 logos for Geode (Geometry Dash) mods. Unofficial fan tool.

It is a single `index.html`. No build step, no dependencies.

## Features

- Layers: import PNG, JPG or WebP, reorder, rename, hide, duplicate, opacity, move, scale, rotate
- Geometry Dash style: stroke that follows the image shape, black outline, drop shadow
- Geode-style frame with gradient ring and editable background (solid, gradient or image)
- Undo and redo, snapping guides, perfect centering, touch support
- Export as 1024x1024 PNG, with optional transparent background

## Run

Open `index.html` in a browser, or host the folder on GitHub Pages.

## Shortcuts

- Ctrl+Z / Ctrl+Shift+Z: undo / redo
- Ctrl+D: duplicate
- Delete: remove layer
- Arrow keys: nudge
- V: select, H or Space: pan
- 0: fit view
- ?: tutorial
